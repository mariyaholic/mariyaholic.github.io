### Subset commands (fonttools; run outside any download directory)
```
pyftsubset MajorMonoDisplay-Regular.ttf \
  --unicodes="U+0020-007E,U+00B7,U+2013,U+2014,U+2190-2199" \
  --flavor=woff2 --layout-features='*' \
  --output-file=MajorMonoDisplay-Regular.subset.woff2
  # rev 6 adds U+2190-2199. Flags other than --unicodes are as in rev 3; Ava ran the rev 6 build on the box.

pyftsubset SpecialElite-Regular.ttf \
  --unicodes="U+0020-007E,U+00B7,U+2013,U+2014,U+2018,U+2019,U+201C,U+201D,U+2026" \
  --flavor=woff2 --layout-features='*' \
  --output-file=SpecialElite-Regular.subset.woff2

pyftsubset JetBrainsMono-VariableFont_wght.ttf \
  --unicodes="U+0020-007E,U+00A0,U+00B0,U+00B7,U+00D7,U+2013,U+2014,U+2018,U+2019,U+201C,U+201D,U+2026,U+2190-2199,U+2212,U+2264,U+2265,U+2500-257F,U+2580-259F" \
  --flavor=woff2 --layout-features='' --no-hinting \
  --output-file=JetBrainsMono-ascii.subset.woff2
  # done by Ava on the box for rev 6: 15,176 B, 279 glyphs, wght 100-800 kept
```

### Fonts per view
- **Light:** Fraunces, Fraunces italic, Newsreader. Labels and UI use system Arial (not loaded). Pages with ↗ / → or ASCII add the JetBrains Mono subset (once; it serves both the Arrows and JetBrains Mono faces).
- **Night:** Major Mono Display, Special Elite, Newsreader. Pages with arrows or ASCII add the JetBrains Mono subset.
- **Never for ASCII:** Major Mono Display and Special Elite (no block or box glyphs).

## Forbidden: never download, place in this folder, or use

Fonts attributed (by fans, unverified) to the show that rev 3/4 referenced. Licences were checked at the rights holders' pages in rev 3 (see `SOURCES.v4.md` for quotes and URLs).

| Font | Rights holder | Why it is forbidden |
|---|---|---|
| **Narrowband Prime** | Image Club (sold via MyFonts) | Commercial; a web licence would have to be bought. Even then it would imitate the show's logo. Free "Narrowband Prime ICG" copies are not usable. |
| **Trixie / TrixieCyr** (now LTR NCND) | Erik van Blokland / LettError | Commercial web licence per domain. The free "TrixieCyr Plain" copies have no authorisation from the rights holder, and it would also imitate the logo. |
| **LoveLetter TW** | Dixie's Delights (1996) | Shareware with no stated web-embedding terms. Off-limits unless the author grants web use in writing. |
| "Lain Font" (ErgoHiki, fan font) | fan | Freeware, non-commercial; web embedding not addressed; franchise-named. |
| The show's logo or wordmark composition, or any imitation | franchise | Off-limits whatever the font licence. |
