How I work

Make it checkable.

I like big questions. Then I try to turn the answer into something other people can check.

Follow the thread

One project can start as a sky map, turn into a data page, and end up as a question in a game. That's fine.

Label things

If something is early, concept art, private or unverified, it says so right where it shows up.

Link the sources

Sources and notes sit next to the public pages, so you can dig further if you want.

Stay a person
