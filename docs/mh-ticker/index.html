MH Ticker

MH Ticker is a Windows app. It shows market prices in the free space of the taskbar. When you click it, a larger panel opens with one card for each symbol. Prices come from the public CNBC quotes. You do not need an account.

Install MH Ticker

Caution

The program does not have a code signature. Download it only from the release page of the source repository.

  1. Go to the latest release.
  2. Download MH_Ticker.exe.
  3. Double-click MH_Ticker.exe.
  4. If Windows SmartScreen shows a message, select More info, then select Run anyway.

The strip moves into the free space of the taskbar. Only one copy can run at a time.

Use the panel

  • Open the panel: click the strip, or click the tray icon.
  • Close the panel: select the minimize button, push Esc, or click the tray icon.
  • Open a symbol on CNBC: click its card. In Ultra, a click locks the card. Use Open on CNBC on the locked card.
  • Copy a price: right-click a card and select Copy.

Each card shows the price, the change for the day in percent and in points, the range for the day, the 52-week range, and the age of the price. A dim price is not current.

Select symbols

  1. Right-click the strip.
  2. Select Symbols.
  3. Select the symbols to show. You can show up to 24 symbols. The strip changes immediately.

To add a symbol that is not in the list, select Symbols > Add symbol... and type a CNBC symbol, for example AAPL or EUR=. The app sends one request to CNBC to check the symbol. If CNBC does not know the symbol, the app does not add it.

To return to the six default symbols, select Symbols > Reset to default.

Change the position

  1. Right-click the strip.
  2. Select Position.
  3. Select one of these options:
    • Auto (default): the app finds free space in the taskbar.
    • Taskbar, left of Start or Taskbar, next to the tray.
    • Floating: drag the strip to a position. The app keeps this position.
    • A corner of the screen.
    • A display, if you have more than one.

Set the update interval

Right-click the strip and select Poll every. The range is 1 to 60 seconds. A shorter interval uses more network data.

Two options can decrease the number of requests:

  • Slow down when nothing moves: when no price changes for 10 minutes, the app polls each 15 seconds. After 30 minutes, it polls each 60 seconds.
  • Rest while the PC is locked: the app polls each 5 minutes while the PC is locked and no alert is set.

Ultra has the two options on by default. Classic has them off.

Settings file

The app keeps its settings in %LOCALAPPDATA%\MH_Ticker\config.json. Ultra uses config_ultra.json in the same folder. To open the folder, select Open config folder in the menu.

The menus apply changes immediately. If you edit the file manually, restart the app.

If the app cannot read the file, it does not overwrite it. It renames the file to config.bad.json and starts with the default settings.

Warning

The webhook value in Ultra is a secret. Anyone with the URL can send messages to your channel. Do not share the settings file or a config.bad.json file before you remove this value.

Check the price feed

Use --probe to check that the price feed operates correctly. The app reads the settings but does not change them.

MH_Ticker --probe
ResultMeaningExit code
PASSThe check is correct.0
WARNThe check failed.1
NOTEThe data cannot show the result, for example when the market is closed. A NOTE does not cause a failure.0
Usage error--dump was used without a folder or without --probe.2

Build from source

Requirements: Windows 10 or later and the latest stable Rust.

cargo test
cargo build --release

The build makes target/release/MH_Ticker.exe and target/release/MH_Ticker_Ultra.exe.

Limits

  • The prices are for information only. They are not investment advice.
  • Fallback price sources are off by default. A fallback price shows age unknown and cannot start an alert.
  • The data use with 24 symbols is not measured.
