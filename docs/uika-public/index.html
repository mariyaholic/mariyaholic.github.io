Inspect the public preview

Use Node 22 or later and work from a public source checkout. Run the check and tests before trying a disposable synthetic estate. Read each command’s help and dry-run behavior before applying changes.

How it works

The command suite validates and manages the documented estate structure. Most writes require --apply, with command-specific exceptions documented in the manual.

Requirements and commands

Node.js 22+; Git for selected deploy/find commands.

Run these from the source checkout where applicable. Commands were source-inspected for this documentation; environment-specific execution is not claimed.

node bin/uika.mjs check
npm test
npm run scrub
node bin/uika.mjs lint --strict
node bin/uika.mjs docs check --strict
npm pack

Limits and safety

This is a source preview, not a published npm package. Do not use an npm install or npx command as if a release existed. Keep real harness homes and credentials out of examples.
