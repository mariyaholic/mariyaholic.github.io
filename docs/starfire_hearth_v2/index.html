Starfire Hearth

Starfire Hearth is a turn-based space strategy game. The simulation and the display are separate layers.

Runtime
Godot 4.7.2 stable
Status
0.1.0-m1 source preview, no release
Source

Run the first scenario

  1. Open the source in Godot 4.7.2 stable. Import the project once: 
    godot --headless --path . --import
  2. Run the data validator and the tests: 
    godot --headless --path . -s tools/validate_data.gd
godot --headless --path . -s tests/run_tests.gd
  3. Start the game: 
    godot --path .
  4. From the title screen, select Scenario 1. Play through to the debrief.

How the game is built

The simulation runs independently of the UI. The game data lives in JSON. The player-facing strings live in strings/en.csv.

Note

Install the matching export templates before you export builds.
