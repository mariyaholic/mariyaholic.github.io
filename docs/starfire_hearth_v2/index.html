Starfire Hearth

Turn-based space 4X with separate simulation and presentation layers.

Source version 0.1.0-m1 · No published GitHub release verified · Source 2c478cb · Changed 2026-11-06 23:53:38 UTC

Source repository ↗

Run the first scenario

Open the source with the pinned Godot version. Import once, run the data validator and tests, then launch the project. Start Scenario 1 from the title screen and play through to the debrief.

How it works

The simulation lives separately from the UI. Data is JSON and player-facing strings live in strings/en.csv. Exporting requires matching export templates.

Requirements and commands

Godot 4.7.2 stable; Matching export templates for packaged builds.

Run these from the source checkout where applicable. Commands were source-inspected for this documentation; environment-specific execution is not claimed.

godot --headless --path . --import
godot --headless --path . -s tools/validate_data.gd
godot --headless --path . -s tests/run_tests.gd
godot --path .
