Ad Astra

Ad Astra is a research program. It analyses astronomical archive data. For each result, it records the source and the evidence level.

Runtime
Python 3.10 or later; hosted runs use 3.12
Status
0.1.0 source preview, no release
Source
mariyaholic/ad_astra, commit 33b3354
License

Run a campaign

  1. Make a virtual environment and install the campaign extras: 
    python -m venv .venv
.venv/bin/python -m pip install -e ".[test,site,campaign]"
  2. Examine the queue of targets: 
    .venv/bin/python -m cygnus.campaign queue
  3. Select the next target. This command writes the specification file: 
    .venv/bin/python -m cygnus.campaign new --next
  4. Run the campaign. Archive retrieval needs a network connection: 
    .venv/bin/python -m cygnus.campaign run campaigns/<slug>.yaml
  5. Make the report: 
    .venv/bin/python -m cygnus.campaign report campaigns/<slug>.yaml
Note

These commands use the macOS and Linux form. On Windows, replace .venv/bin/python with .venv\Scripts\python.exe.

How a run is recorded

Each run records provenance and writes a sky record.

Note

Evidence labels state the strength of the checks. They do not state a confirmed discovery.

Run the tests

Run the test suite from the source checkout: 

.venv/bin/python -m pytest -q

Limits

Warning

Use public or synthetic inputs for examples. Keep personal storage paths and credentials out of reports.
