Ad Astra

Astronomical archive analysis with provenance and explicit evidence levels.

Source version 0.1.0 · No published GitHub release verified · Source 33b3354 · Changed 2026-11-07 03:33:21 UTC

Source repository ↗

Start with the queue

Create a virtual environment, install the campaign extras, then inspect the queue. Select a target with the campaign command; the generated specification identifies the file to pass to run and report. Archive retrieval needs a network connection.

How it works

Each run records provenance and produces a sky record. Evidence labels describe the strength of the checks, not a confirmed discovery. Publishing follows the project’s collection and review process.

Requirements and commands

Python 3.10+; hosted runs use 3.12.

Run these from the source checkout on macOS or Linux. On Windows, replace .venv/bin/python with .venv\\Scripts\\python.exe. Commands were source-inspected; environment-specific execution is not claimed.

python -m venv .venv
.venv/bin/python -m pip install -e ".[test,site,campaign]"
.venv/bin/python -m pytest -q
.venv/bin/python -m cygnus.campaign queue
.venv/bin/python -m cygnus.campaign new --next
.venv/bin/python -m cygnus.campaign run campaigns/<slug>.yaml
.venv/bin/python -m cygnus.campaign report campaigns/<slug>.yaml

Limits and safety

Use public or synthetic inputs for examples. Keep personal storage paths and credentials out of reports.
