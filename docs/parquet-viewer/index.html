Parquet Viewer

Read-only Parquet browsing with schema, row groups and bounded scans.

Source version 0.1.0 · No published GitHub release verified · Source a512fd5 · Changed 2026-11-07 01:30:41 UTC

Source repository ↗

Browse a Parquet file

Build the source and run the CLI against the included fixture. Desktop packaging is a separate Windows-targeted process. Use a disposable file when trying the desktop browser and Find.

How it works

The app reads columnar data and displays rows in pages. Search coverage is bounded and should be read from its status. Footer totals come from metadata rather than an independent full row count.

Requirements and commands

Rust 1.85+; Windows x64 for desktop and Explorer; Cross-platform headless CLI.

Run these from the source checkout where applicable. Commands were source-inspected for this documentation; environment-specific execution is not claimed.

cargo build --workspace --locked
cargo test --workspace --locked
cargo run -p parquet-preview-cli -- tests/fixtures/trades.parquet --rows 20
cargo fetch --locked --target x86_64-pc-windows-gnu
bash scripts/build-desktop.sh --debug

Limits and safety

No public release asset was verified. Keep the worker executable, fonts, help and licences together. Native Windows accessibility and integration need their own acceptance checks.
