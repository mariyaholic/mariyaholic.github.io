Parquet Viewer

Parquet Viewer opens Parquet files read-only. It shows the schema, the row groups and rows in pages, with bounded scans.

Platform
Windows x64 for the desktop app and Explorer; Linux and macOS for the headless command-line tool
Runtime
Rust 1.85 or later
Status
0.1.0 source preview, no release
Source
mariyaholic/parquet-viewer, commit 7553228
License
Apache-2.0

Open a Parquet file

  1. Build the source (see Build from source).
  2. Open the included fixture with the command-line tool: 
    cargo run -p parquet-preview-cli -- tests/fixtures/trades.parquet --rows 20
  3. For the desktop app, package the app for Windows separately (see the commands below).
  4. Use a disposable file when you examine the desktop browser and its Find command.

Use the viewer

The app reads columnar data and shows rows in pages. Check the status bar for the search coverage.

Note

Read the footer totals as file metadata. They are not an independent full row count.

What the viewer shows

The Explorer preview is a per-user Windows preview handler for .parquet files. v1 gives you these things:

  • A footer with the schema, the row-group list and a row count from the metadata. Counts and statistics are explicitly labelled until a complete scan verifies them.
  • Date and timestamp bounds for each column. Each bound has complete, partial or unavailable coverage, and it gives a reason.
  • A virtualized, bounded sample. It renders nested structs, lists, maps, decimals, dates, timestamps and binary values safely.
  • An optional full decoded scan with row, decoded-byte, compressed-byte and time budgets. A cancelled or skipped scan never claims exactness.
  • An About dialog. Push F1 in the preview pane. It shows "Made by Maria" and the free and open source (Apache-2.0) notice.

Market-data heuristics are also part of v1. See Turn on market diagnostics.

Use the headless command-line tool

The CLI is for development, diagnostics and non-Windows verification. The --rows form is in Open a Parquet file. These commands are from the source:

cargo run -p parquet-preview-cli -- tests/fixtures/trades.parquet --scan
cargo run -p parquet-preview-cli -- tests/fixtures/trades.parquet --json
cargo run -p parquet-preview-cli -- --about

Turn on market diagnostics

The heuristics are opt-in, and they stay that way. They check for a constant spread, an open equal to the previous close, return tails and price plausibility. Each report carries an explicit field mapping and the sample coverage. The check can also use an optional local dated reference-price baseline.

  1. Create a settings file with the fields below.
  2. Point the worker at the file with the PARQUET_PREVIEW_SETTINGS environment variable.
{
  "market_profile": {
    "time_field": "time",
    "open_field": "open",
    "high_field": "high",
    "low_field": "low",
    "close_field": "close",
    "spread_field": "spread",
    "instrument": "EURUSD"
  },
  "baseline": {
    "path": "C:\\Users\\me\\baseline.csv",
    "instrument": "EURUSD",
    "licence": "internal research licence 2026"
  }
}

The baseline is a local CSV file. It has date,price columns and an optional instrument column. The file must name the licence or the terms under which it is used.

Note

Without a dated, instrument-specific, explicitly licensed baseline, the viewer reports the price comparison as unavailable.

The heuristics are warnings. They are not proof of fraud, authenticity or integrity, and they are not financial advice.

Register the Explorer preview handler

Releases are published as parquet-preview-<version>-x64.zip. The archive holds the binaries, the licence documents and the registration scripts.

  1. Extract the zip archive.
  2. In the extracted folder, run: 
    powershell -ExecutionPolicy Bypass -File install.ps1
  3. Restart Explorer. The preview pane then opens .parquet files.
Caution

Releases are not code-signed yet, so SmartScreen may show a warning.

To remove the registration, run powershell -ExecutionPolicy Bypass -File uninstall.ps1 from the extracted folder.

install.ps1 and uninstall.ps1 are the conventional entry points. They are thin wrappers over Register-ParquetPreview.ps1, which holds the logic. The scripts warn before they change .parquet associations, and they back up the previous handler. The uninstaller restores the association only if it still belongs to this viewer.

Registration is under HKCU\Software\Classes. No elevation is required.

Note

The handler and the worker must be version-matched and live in the same directory: parquet_preview_windows.dll and parquet-preview-worker.exe.

The script details are in installer/README.md.

Build from source

To package for Windows x64 from a Unix-like host, install the Rust Windows GNU target, a MinGW-w64 cross compiler and linker, Python 3, zip and sha256sum first. Fetch the locked dependencies before you run the offline build script.

cargo build --workspace --locked
cargo test --workspace --locked
cargo run -p parquet-preview-cli -- tests/fixtures/trades.parquet --rows 20
rustup target add x86_64-pc-windows-gnu
cargo fetch --locked --target x86_64-pc-windows-gnu
bash scripts/build-desktop.sh --debug

Rust 1.85 or later and a normal Cargo toolchain are enough for a plain build and test. No Windows target is required for these commands:

cargo build --workspace
cargo test --workspace

The Win32/COM module is behind #[cfg(windows)]. On Linux you can type-check it, but you cannot test it:

cargo check -p parquet-preview-windows --features win-check

For native Windows releases, run scripts/build-windows.ps1. On Linux, run scripts/build-windows.sh with the Windows GNU target and MinGW installed. The Linux script also needs zip.

Both scripts produce dist/ with the binaries, the licence documents, the registration scripts and SHA256SUMS. They also produce one release archive, dist/parquet-preview-<version>-x64.zip. The scripts use the last commit timestamp and remap source paths. Reproducibility also depends on identical toolchains and dependency inputs.

See docs/TESTING.md for everything that still requires real Windows.

Limits

Note

No public release exists. Keep the worker executable, fonts, help and licences together. Run separate checks for native Windows accessibility and integration.

What the viewer does not do

  • There is no SQL and no full-file editing. The Explorer and CLI inspection pipeline is separate from the standalone desktop app.
  • There is no data-network access, no uploads and no telemetry.
  • MT5/MetaTrader support, if configured later, is strictly read-only. This project places no orders and makes no trading calls. It is not affiliated with MetaQuotes; MetaTrader 5 and MT5 are trademarks of MetaQuotes Ltd.

Known limitations

  • Encrypted Parquet files, corrupt files and unsupported logical types are reported, not decoded. v1 handles the codecs that the parquet crate enables: Snappy, Gzip, Zstd, Brotli and LZ4_RAW.
  • Nested date/timestamp leaves are excluded from the top-level date-bounds report. The report states this limitation.
  • Footer counts and statistics come from the file. They are not an integrity check. A full scan is required to claim exact counts.
  • The preview handler targets 64-bit Windows. Store/MSIX packaging, signing, ARM64 and page-index-based virtual scrolling are not part of v1.
  • The worker enforces budgets and is assigned to a job object. A job object is not a security sandbox.
