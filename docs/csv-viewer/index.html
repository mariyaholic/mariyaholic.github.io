CSV Viewer

Read-only CSV browsing, literal search and explicit scan coverage.

Source version 0.1.0 · No published GitHub release verified · Source 44d2ce8 · Changed 2026-11-06 09:48:20 UTC

Source repository ↗

Browse a CSV safely

Build the source using the commands below. The CLI render command reads a file supplied by the user; substitute a disposable CSV fixture for the example path. Desktop packaging is a separate Windows-targeted process.

How it works

In the desktop app, browse by page and use Find for a literal search. A limited scan covers only the reported range; no match is not proof of absence from the whole file. Copying a shortened display value may not copy the full original.

Requirements and commands

Rust 1.85+; Windows x64 for desktop and Explorer; Linux/macOS terminal pipeline.

Run these from the source checkout where applicable. Commands were source-inspected for this documentation; environment-specific execution is not claimed.

cargo build --workspace --locked
cargo test --workspace --locked
cargo run -p csv-viewer -- --render path/to/file.csv
cargo fetch --locked --target x86_64-pc-windows-gnu
bash scripts/build-desktop.sh --debug

Limits and safety

No public release asset was verified. Keep the worker executable, fonts, help and licences next to the desktop executable when building a portable folder. Explorer registration is optional.
