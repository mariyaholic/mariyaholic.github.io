Omoi

Omoi is a Windows program. It keeps a local catalogue of the history of your browsers. History collection and playback capture start only when you select them.

Platform
Windows (desktop app and browser-history collection)
Status
0.1.0 source preview, no release
Source
mariyaholic/omoi, commit f6d7ea9
License
Apache-2.0

Start with a clean catalogue

A clean catalogue keeps your demonstration data separate from an existing catalogue. Set OMOI_HOME to a new temporary directory before you open the UI.

  1. Build the release binaries (see Build from source).
  2. In PowerShell, set OMOI_HOME to a new temporary directory: 
    $env:OMOI_HOME = [IO.Path]::GetFullPath((Join-Path $env:TEMP ('omoi-docs-' + [guid]::NewGuid().ToString())))
  3. Open the UI: 
    .\target\release\omoi.exe ui --open
  4. Turn on history collection, playback and scheduling one by one. Each one starts only when you select it.

Use the catalogue

Search for entries in the UI and examine the results. Export only to a destination that you intend to use. Keep WebView2 and its loader beside the desktop executable.

Build from source

Requirements: Windows, stable Rust. CI uses the Windows GNU toolchain.

Run these commands in PowerShell from the source checkout:

cargo test --locked --all-targets
cargo build --locked --release --bins
$env:OMOI_HOME = [IO.Path]::GetFullPath((Join-Path $env:TEMP ('omoi-docs-' + [guid]::NewGuid().ToString())))
.\target\release\omoi.exe --help
.\target\release\omoi.exe paths
.\target\release\omoi.exe ui --open

Limits

Warning

Omoi can record the history of your browsing. Do not collect or publish real browsing history in a tutorial. Use synthetic data.

No signed public release or native acceptance is claimed on this page.
