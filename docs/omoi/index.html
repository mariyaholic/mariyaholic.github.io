Desktop utilities

Omoi

Local browser-history catalogue with explicit collection and optional playback capture.

Source version 0.1.0 · No published GitHub release verified · Source f6d7ea9 · Changed 2026-11-04 23:45:53 UTC

Source repository ↗

Start with a clean catalogue

Build the source in PowerShell, then set OMOI_HOME to a new absolute temporary directory before opening the UI. This keeps the demonstration catalogue separate from an existing one. History collection, playback and scheduling are separate opt-in actions.

How it works

The desktop package requires WebView2 and its loader beside the executable. Use the interface to search and inspect entries; export only to a destination you intend to use.

Requirements and commands

Windows for desktop and browser-history collection; Stable Rust; Windows GNU toolchain in CI.

Run these from the source checkout where applicable. Commands were source-inspected for this documentation; environment-specific execution is not claimed.

cargo test --locked --all-targets
cargo build --locked --release --bins
$env:OMOI_HOME = [IO.Path]::GetFullPath((Join-Path $env:TEMP ('omoi-docs-' + [guid]::NewGuid().ToString())))
.\target\release\omoi.exe --help
.\target\release\omoi.exe paths
.\target\release\omoi.exe ui --open

Limits and safety

Do not collect or publish real browsing history as a tutorial. No signed public release or native acceptance is claimed here.
