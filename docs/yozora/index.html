Yozora

Yozora is a Windows app. It finds the music or video that plays on your computer and shows it on your Discord profile as Rich Presence. You select which players it can read.

Install Yozora

Caution

The Yozora files do not have a code signature. Windows SmartScreen can show the message “Windows protected your PC”. Compare the checksum before you run the file.

  1. Download Yozora-Setup.exe and SHA256SUMS.txt from the latest release.
  2. In PowerShell, get the checksum of the installer: 
    Get-FileHash .\Yozora-Setup.exe -Algorithm SHA256
  3. Make sure that the value is the same as the value for Yozora-Setup.exe in SHA256SUMS.txt. If the values are different, do not run the file.
  4. Open Yozora-Setup.exe. The installer installs Yozora for your user account only. It does not ask for administrator rights.
  5. If SmartScreen shows a message, select More info, then select Run anyway.
  6. Open Yozora from the Start menu. The control panel opens.

A portable Yozora.exe is also on the release page. The automatic update procedure does not apply to the portable file.

Set up the Discord card

Discord desktop must run on the same computer. You do not need a Discord client secret.

  1. Start Discord desktop.
  2. Open the Yozora control panel. The setup checklist shows three checks: Discord found and connected, Media detected and Card visible on Discord.
  3. Play a track in a music player.
  4. Select Send test card. Discord shows the card “Yozora test card” for 15 seconds.
  5. If the card does not show, in Discord go to Settings > Activity Privacy and turn on Share my activity.

When all checks pass, the checklist closes. To show it again, select Show setup checklist in the Diagnostics section.

Select sources and priority

A source is a type of player, for example Spotify or a browser. Yozora shows one source at a time. The source at the top of the priority list wins when it plays.

  1. In the control panel, find the source list.
  2. Select the check box of each source that Yozora can read.
  3. To change the order, drag a source by its grip. Or, select the source grip and push the Up or Down arrow key.
  4. Select Apply.
Note

On a new install, Browser media / videos and Other media players are off. YouTube, Twitch and background browser tabs each have a separate switch. These switches are also off by default.

Pause sharing

A pause removes your Discord card in approximately five seconds. Yozora continues to find media, but it does not send it to Discord.

  • To pause, select Pause sharing for 1 hour or Pause until I resume in the tray menu. Or, select Pause sharing in the control panel.
  • To stop the pause, select Resume sharing.

A pause stays in memory only. When Yozora starts again, the pause stops.

Update Yozora

Yozora checks GitHub for a new release approximately one time each day. A check does not install a release.

  1. To check now, go to the Startup section and select Check for updates.
  2. When a new release is available, select Update now.
  3. Yozora downloads the installer, compares its SHA-256 checksum with SHA256SUMS.txt and installs it. Your settings stay the same.
  4. Open the control panel again from the tray icon.
Note

An unsigned build checks the checksum only. The checksum comes from the same release as the installer. It finds a damaged download. It does not find a changed release. If this is not sufficient for you, update manually from the release page.

To stop all update checks, add this to %APPDATA%\uika-resonance\cadence.toml:

[update]
check = false

Remove Yozora

  1. Go to Settings > Apps > Installed apps.
  2. Find Yozora and select Uninstall.
  3. The uninstaller asks Also remove my settings and cached data? Select Yes to remove all data. Select No to keep it.

If you select Yes, the uninstaller removes these items:

  • %APPDATA%\uika-resonance (settings)
  • %LOCALAPPDATA%\uika-resonance (artwork cache, logs, status files)
  • %TEMP%\uika-probe
  • The Spotify entries in Windows Credential Manager

Build from source

Requirements: Windows and Go 1.27.1 or later.

go mod download
go test ./... -count=1
go build -ldflags=-H=windowsgui -o Yozora.exe ./cmd/yozora
./Yozora.exe serve

Yozora.exe without an argument opens the control panel. With an argument, it operates as a command-line tool.

Commands
CommandFunction
serveStarts the background process and the tray icon.
statusShows the current state.
doctorRuns diagnostic checks.
setupRuns the setup in the terminal, for scripted installs.
install / uninstallTurns start at Windows sign-in on or off.
stopStops a Yozora process that started from the same file.
versionShows the version. A local build shows dev.
