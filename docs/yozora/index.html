Set up the Windows app

Choose the verified installer or portable executable from the release page and compare its checksum with SHA256SUMS. Open the panel, choose the sources you want, arrange their priority and apply the change. Discord desktop is required to display presence.

How it works

Closing the panel leaves the tray process available; use the tray quit action to stop it. Browser-specific detection and startup behavior are opt-in.

Requirements and commands

Windows; Go 1.27.1+ for source builds; Discord desktop for local Rich Presence.

Run these from the source checkout where applicable. Commands were source-inspected for this documentation; environment-specific execution is not claimed.

go mod download
go test ./... -count=1
go build -ldflags=-H=windowsgui -o Yozora.exe ./cmd/yozora
./Yozora.exe serve

Limits and safety

The binaries are unsigned. Inspect source and verify checksums before running. For examples, use the synthetic UI harness rather than personal listening history.
