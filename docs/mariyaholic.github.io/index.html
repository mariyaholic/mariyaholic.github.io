Preview a site change

Clone the source and start a local HTTP server from the repository root. Open the local address in a browser, check the changed pages and navigation, then stop the server with Ctrl+C.

How it works

The site is static HTML, CSS and JavaScript. The shared stylesheet contains the palette and window framing; fonts are stored locally. Use a branch and pull request for changes.

Requirements and commands

Modern browser; Python 3 for local preview.

Run these from the source checkout where applicable. Commands were source-inspected for this documentation; environment-specific execution is not claimed.

python3 -m http.server 8080

Limits and safety

Preserve existing noindex metadata, accessibility and reduced-motion behavior. The website has no source semantic version.
