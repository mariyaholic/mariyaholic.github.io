Personal website

This website is static HTML, CSS and JavaScript. It has no build step and no framework. GitHub Pages serves the files from the main branch.

Preview the site

Requirements: Python 3 and a modern browser.

  1. Clone the source: 
    git clone https://github.com/mariyaholic/mariyaholic.github.io.git
cd mariyaholic.github.io
  2. Start a local server from the root of the repository: 
    python3 -m http.server 8080
  3. Open http://127.0.0.1:8080/ in a browser.
  4. Examine the pages that you changed and their links.
  5. To stop the server, push Ctrl+C.
Note

Use the local server. Do not open the files directly from the disk. Some browsers block parts of a page that opens with a file:// address.

Change the site

Caution

Do not push to main. All changes go through a branch and a pull request. The owner merges the pull request.

  1. Make a branch from main, for example site/fix-arcade-links.
  2. Edit the HTML, CSS or JavaScript files.
  3. Preview the change. Use the procedure in Preview the site.
  4. Commit the change and push the branch.
  5. Open a pull request to main.

After the merge, GitHub Pages publishes the site again in one or two minutes.

Two looks

The site uses two stylesheets. Use one stylesheet on each page. Do not use the two together.

  • Main look (site.css and site.js): portfolio, programs, games and personal pages. Each top-level <section> in <main> is a window. Give it class="win" and data-win="FOLDER\NAME.TXT".
  • Document look (plain.css only): documentation and papers. It uses system fonts and no JavaScript. Documentation pages use the dark theme (theme-docs). Paper pages use the light, wiki-like theme (theme-paper).

Rules and limits

  • Keep the noindex metadata on each page unless the owner decides to change it.
  • Keep the accessibility and reduced-motion behaviour.
  • Do not add external requests. The only external request is the YouTube player in the FLUORITE.EYE window on the home page.
  • Sound and music are off by default. A browser starts audio only after a click or a key push.
