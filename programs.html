Programs

Small programs, no bloat.

Two Windows programs you can download and run, and four libraries split out of them. All of it is public on GitHub.

Neither program is code-signed yet, so Windows SmartScreen will ask first. Choose More info, then Run anyway.

Rust · Windows 10 and up · v1.2.3 · MIT

MH Ticker. Prices in the taskbar.

A price strip that sits in the empty part of the Windows taskbar. Click it and it opens into a panel in the middle of the screen. Minimise it and it goes back.

  • PricesPublic CNBC quotes. No account, no key, no payment.
  • SymbolsUp to 12 of 23: metals, crypto, US futures, oil, gas, FX, yields, the VIX and major indices.
  • FootprintAbout 5 MB of memory. Plain Win32 and GDI, no GUI toolkit or webview.
  • FullscreenIt hides while a game or video is fullscreen.

Go · Windows · v0.1.5 · MIT

Yozora. Your music, on Discord.

It notices what's playing on Windows and shows it as Discord Rich Presence, with the album art and a Listen button. Everything a presence app doesn't need is cut, so it can run in about 10 MB of memory.

  • SourcesSpotify, Apple Music, YouTube Music, browsers and other players, in a priority order you set.
  • DiscordTalks to the desktop app over its local pipe. No client secret.
  • InstallOne installer, for your user only, no admin prompt. A portable .exe is in the same release.
  • PanelA small control panel for sources and priority. It closes to the tray.

Download Yozora-Setup.exe ↗Source on GitHub

Libraries

Pulled out, then frozen.

Parts of Yozora and of an older site, split into their own modules. They're archived on GitHub, so you can read them but they don't take changes. None has a licence file yet.

  • discordipc ↗Go · Discord Rich Presence over the local pipe, no SDK or cgo
  • nowplaying ↗Go · what Windows is playing, from its media controls, standard library only
  • winutil ↗Go · tray icon, Credential Manager, autostart, single instance
  • sitekit ↗Node and Python · builds a page from a JSON catalog, then audits it in a browser

This site's source is public too: mariyaholic.github.io.
