Summary

Let a(n) be the largest size of a set S ⊆ {0,1}n in which every three distinct points form only strictly acute angles in ℝn (OEIS A089676). The paper gives a dependency-free Lean 4.35.0 library for these cubic acute sets. Every result below is checked by the Lean kernel.

  1. Four definitions of an acute set are equivalent: the dot-product condition, a Boolean “sandwich” exclusion, a coordinate separation criterion and a bit-packed decision procedure.
  2. General bounds |S| ≤ 2n and |S| ≤ 2n−1 for n ≥ 2, and the composition constructions of Bevan (2006) and Harangi (2011, case s = 2).
  3. Exact values a(0..7) = 1, 2, 2, 4, 5, 6, 8, 9, with lower-bound witnesses for 0 ≤ n ≤ 15.
  4. New lower bounds for 16 ≤ n ≤ 24 and 47 ≤ n ≤ 53 that exceed the OEIS table of 2 November 2026.

Upper bounds for a(8) = 10, a(9) = 16 and a(10) = 17 are not yet formalized. Exact values for n ≥ 11 remain open.

This summary is a shortened form. The PDF has the full abstract and the provenance statement.

New lower bounds

For 16 ≤ n ≤ 24, the witnesses come from iterated bipartite 2-colouring lifts. For 47 ≤ n ≤ 53, the bounds come from Bevan products of those witnesses and from monotonicity.
