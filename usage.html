      How it works

      Private every hour, public rounded.

      An hourly job on my PC reads the usage records my coding tools already write, adds them to a private ledger, and builds one small rounded file. It keeps nothing finer than a week, and it leaves out sessions, projects, paths, models per session, accounts and keys. The file is replaced each hour on a data-only branch, so this site is not rebuilt and its history does not grow.

      If my PC is asleep or off, the file stops updating and this page says so. Gemini and Antigravity keep no token counts on disk, so they show a quota line only once a reading exists.
